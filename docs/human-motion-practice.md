# 人間らしい動きの練習と検証

人間らしさを一つの終点誤差で判定しない。現行の身体はVRChatへの位置入力であり、
物理ロボットのトルク制御や、接触・重心を観測した物理RLとは異なる。

## 必要な要素と根拠

- 身体の対応：同じ立位・身長・tracker対応でFBT校正を行い、鏡で腕・脚への反映を確認する。
  校正入力を送ったことと、アバターに正しく反映されたことは分ける。
  [VRChat Full-Body Tracking](https://docs.vrchat.com/docs/full-body-tracking) と
  [IK 2.0](https://docs.vrchat.com/docs/ik-20-features-and-options) はアバター骨格、校正、
  頭・腰の拘束などによって結果が変わることを説明している。
- 動作事前分布：[DeepMimic](https://xbpeng.github.io/projects/DeepMimic/) は模倣目標と
  タスク目標を併用する。[AMP](https://arxiv.org/abs/2104.02180) は動作資料から
  遷移のスタイル報酬を学ぶ。MyuMIQでは既存のライセンス確認済み動作とactorを維持し、
  目標達成だけの更新で元の姿勢を壊さないよう復習と退行評価を行う。
  現行の復習は静的姿勢のモデル評価であり、AMPの識別器を実装したものではない。
- 時間的な滑らかさ：手の到達運動に関する
  [Flash & Hogan (1985)](https://pubmed.ncbi.nlm.nih.gov/4020415/) は加速度の変化を
  小さくするモデルを検証した。この考えを診断指標として参照し、全身の自然さを
  その値だけで保証する扱いにはしない。
- 足と身体の協調：終点だけ足を戻せても、途中で滑ったり浮いたりすれば自然とはいえない。
  支持足の位置、床、速度・加速度・jerkを軌道全体で記録する。trackerの床面は
  接触センサーやアバターの靴底の観測とは区別する。
- 目的の連続性：身体条件の達成後も保持する。全身を回すLOOK_ATは足・頭の条件を
  変えうるので、BODY_GOALへの互換な上書きとしない。新しい明示的な身体依頼は受け付ける。

## 実装した最小の練習経路

`condition_training` は、既存のPAMIQ候補専用Trainerに元の条件・許容誤差と
滑らかさの目的を追加する。未指定成分は条件誤差に含めない。現在姿勢からだけでなく、
候補自身が通る途中の予測状態からも短い練習を行う。床に違反する予測は開始状態にしない。
この予測状態に実機観測のIDを発行しない。

```sh
python -m myumiq_vrchat.condition_training \
  --tasks ../artifacts/tasks.json --cases ../artifacts/practice.json \
  --prior ../artifacts/prior --reference-corpus ../artifacts/licensed-corpus \
  --baseline ../artifacts/original/candidate-actor.pt \
  --out ../artifacts/practice-001 --updates 200 --learning-rate 0.00001
```

casesは`condition_validation`と同じ形式。名前付き`start`の代わりに、11部位と
中立入力の`start_pose`を渡して観測姿勢から練習できる。両方の同時指定は拒否する。
元の観測時刻・試験・信頼度の記録は外部の課題作成記録に残す。
開始姿勢を渡すこと自体は、アバターの自然さや接触を教師データにしたことを意味しない。
trainとheldoutの両方が必須で、同一条件を
両方へ複製しない。heldoutは候補選択用validationであり、採用後の最終試験ではない。
指定したモデルと保存した学習状態の出力が一致することを更新前に確認する。
保存するのは候補であり、実機の推論モデルに同期しない。SACの確率的更新数は0。

検証では元の条件を達成したか、床、全行程の足のずれ、急な加減速、停止を含めたjerk、
既存参照の成績を比較する。直前の候補と最初のbaselineの両方を比較し、
不採用だった候補から練習を再開しても退行を引き継いで合格扱いにしない。
baselineの場所とhashは次の練習へ引き継ぐ。古い記録からの再開時は明示的に指定する。
未達を平均誤差で隠さず、既存動作の退行も不採用にする。
参照の合計成功数だけでなく、以前達成した各参照の到達も保つ。
`--reference-fraction`と`--reference-anchor-weight`で、復習の割合と
その参照で元のactorの出力を保つ重みを調整できる。採用条件は緩めない。
合格は限定実機試験への入口にすぎない。鏡の見た目・校正・関節対応・自然さの確認は別途必要。

有限モーションの大きさを変える場合は、動作資料の基準姿勢と現在の校正基準が一致するかも
確認する。手だけを大きくしたつもりでも、基準の違いが足や胴体の不要な移動を生む。
理想の立位だけでなく、保存した実機の開始姿勢と直前の動作の終点から、同じactor・
MotionBufferで連続実行を評価する。途中の追従誤差でphaseが止まった場合、先読みも
現在phaseを追い、追従確認後に再開する。到達不能やactorの能力不足は残りうるので、
時間切れ・未完了を許容誤差の緩和で成功に変えない。

残る範囲：画像からの自己姿勢・接触推定、動作資料に対する遷移スタイル識別器、
自然さを満たす部分条件からの姿勢生成、動的な対象への接触。鏡の静止画像や
デバイスの受信結果を、これらの習得や教師ラベルと呼ばない。

周期動作には任意の`exit_goal`を指定できる。例えば足踏みの定義に
`"exit_goal": "STAND", "exit_duration_s": 4.0, "exit_position_tolerance_m": 0.04`
を設定すると、実行期限の最後の4秒を、同じactorによる設定済みSTANDへの遷移に使う。
動作全体の時間は4秒より長くする。終わりの姿勢は現在位置・向きに合わせて開始時に固定し、
動作の観測と終点での新しい複数回の観測がそろってから成功とする。
未到達でも期限は延長しない。動作ごとの明示設定であり、全動作を立位へ戻す規則ではない。
新しい指示や取消はこの遷移より優先する。controllerによる移動の歩行参照には適用しない。
`exit_position_tolerances_m`で部位別の位置許容誤差を上書きできる。
例えば全身8cm・`{"left_foot": 0.02, "right_foot": 0.02}`なら足だけ2cmを要求する。
実行前に決めて、部位ごとの誤差と範囲を結果に記録する。過去の未達を成功に書き換えない。
